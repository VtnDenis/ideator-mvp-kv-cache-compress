How It Works

The eOptShrinkQ algorithm in three steps.

01

SVD Spectral Denoising

Decompose KV cache with singular value decomposition. Truncate noise components while preserving signal energy (85-95%).

torch.linalg.svd
02

8-Bit Quantization

Quantize the denoised cache to INT8 using per-channel scaling. Noise removal ensures near-lossless quantization.

uint8 per-channel
03

Drop-In Callback

Integrate with 2 lines of code. Works with any Hugging Face transformer model during generation. Dequantize on-the-fly.

model.generate(callback=...)

Quick Start

Two lines to 4x memory reduction.

demo.py 
from kv_cache_compress import KVCacheCompressionCallback
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model = AutoModelForCausalLM.from_pretrained("gpt2")
tokenizer = AutoTokenizer.from_pretrained("gpt2")
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

# Create callback — that's it
callback = KVCacheCompressionCallback(
    keep_ratio=0.85,
    compress_every_n_tokens=128,
)

inputs = tokenizer("Once upon a time", return_tensors="pt")
outputs = model.generate(
    **inputs,
    max_new_tokens=512,
    do_sample=True,
    temperature=0.7,
)

# View compression statistics
print(callback.get_stats())
